## htmlのviewpointとは
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
スマートフォンなどの画面でWebページをどう表示するかをブラウザに伝える設定。


`contest="width-device-width`はデバイスの幅で表示する設定

`initial-scale=1.0`は初期の画面表示比率の設定

## jsのscript内のtype
```html
<script type="module" src="js/main.js"></script>
```

`type="module"`はJSをES Modulesで扱うかの設定。

この設定がないと、スクリプトとして扱われる。

ES Modulesだと、`import`、`export`が使用できる。
スクリプトでも`<script src="xxx"></script>`のような形でさらに読み込みはできるが、依存関係が不明瞭になり、読み込みの順番を守らないといけなくなる。

今回だと、divエレメントにclass属性としてwhite、blackを追加することで、CSSによる描画でコマを表現している。

しかし、これはJSでコマ用のdivを作成し追加することでも表現できる。

## CSSのbeforeやafter
```CSS
.cell.black::after {
    content: "";
}
```

このようなときに使用する`before`や`after`は指定の前後に疑似要素を生成するもの。

これがあると、DOMとしてはそのエレメントがあるだけだが、描画としてはそのエレメントの前後に装飾を追加できる。

ただし、`content`が必ず必要。
