## HTMLとCSSの関係

HTMLは構造を意味論で決める役割。CSSは見え方を変える役割。

下記のような`class="player black-player"`と`class="player white-player"`がある。
```HTML
<div class="disk-count">
    <div class="player black-player">
        …
    </div>

    <div class="player white-player">
        …
    </div>
</div>
```
このとき、divは`display: block`なので、順番に縦方向に配置されるが、CSSのflexで横方向に変更する。

ここでの疑問は、最終的に横方向に配置するなら、横配置されるエレメントを使用したほうがいいのでは？と思った。

しかし、調べたところ、ここはdivが正しく、理由としては、配置や見た目でエレメントを選択せずに、意味論で選択するのが正しい。

`class="disk-count"`の中に2つの要素が存在することを構成として持たせておくほうが、1つの枠の中に2つの要素が並列して存在することを意味付けられる。

そして、それをCSSでどう配置するか、どう見せるかを決める。

HTMLとCSSを分けて扱うことで、例えば縦に並べるように仕様が変わった際も、CSSを変えるだけでよく、HTMLは変更せずにすむ。

## CSSのposition

要素を配置する基準を指定する
- static
    - デフォルト。画面のレイアウトに従う。
- relative
    - 子が`position: absolute;`の起点にする
- absolute
    - 画面レイアウトから外れ、`position: relative`を持つ親を起点にする
- sticky
    - 通常配置+スクロールに応じて固定
