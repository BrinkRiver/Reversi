# Reversi

A Reversi game built with HTML, CSS, and JavaScript.

This project is primarily intended for learning and practicing JavaScript through the development of a complete board game.

The goal is to implement the logic, user interface, and game flow while keeping the code maintainable and easy to extend.

## Features

- 8 x 8 Reversi board
- Two-player gameplay
- Turn management
- Valid move detection
- Automatic disk flipping
- Pass detection
- Game-over detection
- Disk count display
- Winner determination

## Technologies

- HTML
- CSS
- JavaScript
